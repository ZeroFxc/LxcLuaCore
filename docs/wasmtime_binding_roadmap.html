wasmtime 绑定扩充路线图

LXCLUA-NCore · lwasmtime.c 现状分析 · 基于 wasmtime v48.0.1 C API 头文件调研 · 2026-09-04

一、结论

完全可以继续扩充，且v48 预编译库已经把能力全部编译进去了（conf.h 显示 WASI、WASI_HTTP、WAT、CACHE、ASYNC、COMPONENT_MODEL、GC、THREADS、POOLING_ALLOCATOR、COREDUMP、ADDR2LINE、DEMANGLE 全部开启），只是 lwasmtime.c 还没有绑定这些 C API。当前绑定已覆盖 Engine/Store/Module/Instance/Func/Memory/Global/Table/Linker 的基础面（含 fuel、epoch、GC、shared-memory、externref），但 WASI、Component、Async、WAT 转换、Trap 对象、Linker 深化等高级面是空白。

二、优先级矩阵（价值 × 工作量）

P0 WASI 系统接口

让 WASM 模块访问文件、环境变量、标准 IO 与网络。绑定链路极简：config → context → linker 一行。

价值 5/5 · 成本 2/5

P0 WAT→WASM 转换

单函数 wasmtime_wat2wasm 封装，Lua 侧直接编译 WAT 文本，替代已移除的 wat2wasm。

价值 4/5 · 成本 1/5

P1 Trap 对象 + trap code

暴露陷阱分类（内存越界/除零/栈溢出/out-of-fuel/interrupt），错误可诊断。

价值 3/5 · 成本 2/5

P1 Linker 深化

define_instance / define / allow_shadowing / 未知导入兜底 / instantiate_pre，打通模块间互操作。

价值 4/5 · 成本 2/5

P1 模块编译缓存

config 加载磁盘缓存，重复加载大模块显著提速。

价值 3/5 · 成本 2/5

P2 Async 异步调用

continuation 机制接 Lua 协程/事件循环，支持异步 WASM 函数 await。

价值 3/5 · 成本 4/5

P2 Component Model

下一代 WASM 组件（WIT 接口），120+ 新 API，工程量最大，愿景最大。

价值 4/5 · 成本 5/5

P2 SharedMemory 深化

补 wasmtime_sharedmemory_grow 与线程模型细节。

价值 2/5 · 成本 1/5

P3 GC 引用类型操作

structref/arrayref/eqref 的创建与转换，补齐 GC 类型面。

价值 2/5 · 成本 3/5

P3 Pooling 资源配额

内存池配置，性能与资源隔离。

价值 2/5 · 成本 2/5

P3 Coredump/日志/栈回溯

崩溃转储 + addr2line 栈还原，调试利器。

价值 2/5 · 成本 3/5

三、推荐落地顺序与关键 API 形态

步骤功能核心 C API 调用链对应 Lua API（建议）
①WAT 转换wasmtime_wat2wasm(wat, len, &wasm)wasmtime.wat2wasm(wat_string)
②WASIwasi_config_new() → wasmtime_context_set_wasi(ctx, cfg) → wasmtime_linker_define_wasi(linker)wasmtime.newWasi{argv=…, env=…, stdin=…, preopenDirs=…}
③Trap 诊断wasmtime_trap_new_code() / wasmtime_trap_code()trap:code() / trap:message()
④Linker 深化wasmtime_linker_define_instance() / define() / allow_shadowing()linker:defineInstance() 等
⑤编译缓存wasmtime_config_cache_config_load(cfg, path)newEngine{cache="./.cache"}
⑥Asyncwasmtime_async_call() + wasmtime_async_continuation_t配合 leventloop/lpromise 的 await 语义
⑦Componentwasmtime_component_new() + component linker/instance 全套wasmtime.newComponent() 系列
注：价值/工作量评分为基于 C API 头文件与封装工程量的工程师评估建议，非客观度量。已核验的事实包括：v48 预编译库 conf.h 开启的功能开关、各候选 API 在头文件中的真实存在性与签名。
